Dự án Web

  • Website Bán Hàng

    Đây là dự án website bán hàng online được xây dựng nhằm hỗ trợ người dùng xem và mua sản phẩm trực tuyến. Website có giao diện hiện đại và thân thiện với người dùng.

    Dự án sử dụng HTML, CSS và JavaScript để xây dựng giao diện và xử lý các chức năng như thêm sản phẩm vào giỏ hàng, tìm kiếm và lọc sản phẩm.

    Hiện tại mình đang phát triển thêm chức năng thanh toán, quản lý đơn hàng và tối ưu giao diện responsive trên điện thoại.

    • Công nghệ sử dụng:

                    HTML
                CSS
                JavaScript

    Tính năng chính:

    • Hiển thị danh sách sản phẩm
    • Tìm kiếm sản phẩm
    • Thêm sản phẩm vào giỏ hàng
    • Responsive trên điện thoại và tablet

    Dự án Mobile

  • Website Giới Thiệu Bản Thân

    Đây là website portfolio cá nhân dùng để giới thiệu thông tin bản thân, kỹ năng, chứng chỉ và các dự án đã thực hiện.

    Website được thiết kế bằng HTML5 và CSS3, có bố cục rõ ràng và responsive để hiển thị tốt trên nhiều thiết bị khác nhau.

    Mình đang tiếp tục cải thiện giao diện, thêm animation và tối ưu trải nghiệm người dùng để website chuyên nghiệp hơn.

    • Công nghệ sử dụng:

                    HTML5
                CSS3
                JavaScript

    Tính năng chính:

    • Hiển thị thông tin cá nhân
    • Danh sách kỹ năng và chứng chỉ
    • Responsive trên nhiều thiết bị
    • Thiết kế giao diện hiện đại

    Dự án Desktop

  • Mini Java Project

    Đây là dự án Java mini được xây dựng để luyện tập tư duy lập trình hướng đối tượng và xử lý dữ liệu.

    Chương trình có các chức năng cơ bản như quản lý thông tin, thêm, sửa, xoá dữ liệu và thao tác với file bằng Java.

    Hiện tại mình đang học thêm về Java Collections, JDBC và cải thiện giao diện console để chương trình dễ sử dụng hơn.

    • Công nghệ sử dụng:

                    Java
                OOP
                File Handling

    Tính năng chính:

    • Thêm dữ liệu
    • Cập nhật dữ liệu
    • Xoá dữ liệu
    • Quản lý dữ liệu bằng file
