Kỹ năng của tôi

  • HTML5

    Thành thạo xây dựng cấu trúc website bằng HTML5, semantic tags và tối ưu nội dung web.

    Mức độ: Advanced

  • CSS3

    Có khả năng thiết kế giao diện responsive, animation và layout bằng Flexbox/Grid.

    Mức độ: Advanced

  • JavaScript

    Sử dụng JavaScript để xử lý sự kiện, thao tác DOM và tạo website tương tác.

    Mức độ: Intermediate

  • ReactJS

    Xây dựng giao diện component-based, quản lý state và tạo SPA hiện đại.

    Mức độ: Intermediate

  • Git & GitHub

    Quản lý source code bằng Git, làm việc nhóm và sử dụng GitHub hiệu quả.

    Mức độ: Intermediate

  • UI Design

    Thiết kế giao diện thân thiện người dùng, chú trọng trải nghiệm và tính thẩm mỹ.

    Mức độ: Beginner

Công cụ & Công nghệ

  • VS Code

    Trình soạn thảo code chính dùng để phát triển website.

  • Git

    Quản lý phiên bản source code và làm việc nhóm.

  • GitHub

    Lưu trữ và chia sẻ dự án lập trình trực tuyến.

  • Figma

    Thiết kế giao diện UI/UX và prototype website.

  • Chrome DevTools

    Kiểm tra và debug giao diện web.

  • Node.js

    Môi trường chạy JavaScript phía server.
